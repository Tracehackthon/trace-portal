# 跟着解释懂了，自己判断时又断了

> 你解释的时候我觉得懂了，但换一段材料、离开你的解释，我又不知道怎么判断。

来源：用于检验链路的情境假设，尚未经过用户验证。

## 发生在什么时候

初次讨论时可能还没有显露，后来自己阅读或再次接续时才发现。

例如，用户看了一篇讨论“相关与因果”的知乎文章，听过 Agent 的解释后觉得懂了；读到另一篇文章时，却仍然不知道怎样辨别其中的推论。

## 当前链路哪里还不够

- 用户说“懂了”，不等于已经能够独立做出其中的区分。
- 再带回一次解释，可能让讨论依然顺畅，却没有找到用户具体断在哪里。
- 已有正文写了“写下来不等于理解”，但还需要具体的帮助过程，不能只停在这句提醒上。

## 产品可以怎样帮助

- 用户愿意时，换一个贴近他的例子，给他先说自己判断的空间，不急着把答案完整讲完。
- 根据他实际说出的内容，找到混淆或断掉的那一处，再补解释或对照，不凭一句“懂了”或“不会”判断全部理解。
- 让他能够看见自己刚才为什么分不开、现在多分清了什么；仍不明白也可以明确留下。
- 不因此把产品变成强制考试，也不要求每次讨论后复述一遍。

有时 Agent 继续说得更多，不是最有帮助的动作；用户自己辨认、尝试和表达，也需要空间。

## 用户的感受

> - 我不只是觉得解释很有道理，而是逐渐知道自己能判断什么、还不会什么。
> - 我可以说错、说不清，产品会从那里帮我，而不是马上再给一整套答案。
