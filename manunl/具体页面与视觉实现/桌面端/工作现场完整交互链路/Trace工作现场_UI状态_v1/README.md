# Trace 工作现场：五种核心 UI 状态 v1

生成日期：2026-09-15。

本组是用户要求的桌面端静态视觉参考，承接本轮关于“工作现场完整 UI 交互链路”的讨论。不是可点击原型，也不表示宿主接入、工作影响追溯或长期理解更新已经实现。

## 同一个案例

当前工作：在 Codex 的 harness 项目中实现「从知乎留下一点」。

过去的理解参与这次保存交互；用户在原型试用时留下新的担心；随后带回一次具体观察，比较它可能如何修正自己的理解。图片内的任务、原型、检查记录和使用结果均为说明交互的假设内容，不是项目实际验收证据。

## 五种状态

| 图片 | 从哪里进入 | 此时可以做什么 |
| --- | --- | --- |
| 01-工作总览态.png | 从首页工作入口或工作旁的悬浮入口展开 | 看清当前任务、本次带入及一处具体取舍 |
| 02-带入展开态.png | 点击“查看这次怎样用” | 看来源与相关性；调整为本次参考、先试或不用 |
| 03-影响追溯态.png | 点击“查看实际影响” | 对照理解、取舍、产物及可核验依据，区分实现与实际效果 |
| 04-发现展开态.png | 工作中输入一条新想法并展开 | 先留一下、展开想想或用于当前工作；可核对建议关联 |
| 05-结果比较态.png | 点击“带回结果”或输入新结果 | 对照上次问题和实际观察；先留结果、进入修改确认或再试 |

这些是一个工作现场的不同状态，不是必须依次走完的五步，也不是五个独立导航模块。

## 视觉与交互约束

- 同一 Trace 品牌、项目任务锚点、象牙白与青绿色、水墨背景、可读的半透明内容表面。
- 无固定侧栏；左下角仅保留个人区域；飞鸟表示一个当前焦点。
- 本次带入和带回结果区分方向，不使用笼统“已应用”或自动通关进度。
- 事实、解释、建议修改分开。结果比较态中的修改尚未生效，下一步需用户确认。
- 工作中新发现不自动成为长期规则；候选关联可以不接受。
- 生成图用于构图、信息层级与状态参考，中文文案及精确控件状态在实现前仍需核对。

## 本轮未展开

切换工作选择器、无关联内容/无接入等空状态、冲突处理、修改差异确认与提交后的回执、跨任务比较，以及飞鸟运动与过渡动画。本组不宣称穷尽所有边界或完成可交互验证。

## 生成与保存

使用内置 image_gen 生图工具，未使用 CLI 或自建 API 调用。调用接口未暴露可选模型型号，未额外指定或声称某个具体模型版本。

每张图单独调用生成；02 做过一次针对正文缺字及按钮选中状态的修正。最终图片均为 1672 × 941 PNG，复制后逐一核验 SHA-256 与生成源文件一致。原生成文件保留；此前的核心功能概念图未覆盖。
