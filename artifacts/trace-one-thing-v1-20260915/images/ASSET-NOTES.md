## 为什么不直接复用旧背景

已目视比较旧首页和同日七图“在意的事” ready 背景：

1. 七图背景上半部山体更密、月球在画面内偏左；本套 02 的月球贴右缘、左右低丘、中央大面积留白，底角有近景竹叶。直接替换会改变整幅构图。
2. 旧首页背景右侧为明显的大型玻璃波峰，底部有两颗小球；新内页是低丘树林与开阔水面，也不一致。
3. 06 总览不只是去掉内页面板：月球位置回到画面内、气泡后方有横跨画面的层叠山丘、没有近景竹叶。故有第二张独立环境的明确缺口，不是为每页重生成一张背景。

生成只删除界面、鸟、节点和人工曲线并补齐遮挡处环境。背景保留自然光斑，细线/节点/鸟均由 UI 模块叠加。自然山水受遮挡区域是生成补齐，不声称精确恢复了概念图背后不存在的像素。

## 鸟的透明与定位

停驻鸟脚点 `[772,588]`；起飞鸟脚点 `[750,955]`，坐标相对于各自裁切 PNG。两个姿态应使用同一源像素缩放比例，不能强行设成相同 CSS 宽度。例如源像素倍率 `0.09`：

```text
perched: width 97.74 px; image origin relative to foot -69.48,-52.92 px
takeoff: width 104.04 px; image origin relative to foot -67.50,-85.95 px
```

旧 `images/repaired/repair-manifest.json` 含原始棋盘格生成失败、修复脚本、被拒绝的诊断、保护白腹/眼/腿检查及重放哈希。本次不重启失败的透明生图路线，未扩大用户以前的脚本授权；只复制已批准的两件 PNG，复查真 alpha 范围为 0—255，并亲看旧小尺寸对照图。

这仍是两张静态姿态：可以路径运动和短暂姿态交叉过渡，但不能声称自然振翅。高倍放大时 1—2 个源像素的浅色羽缘仍属估计，不是高分辨率完美抠像。
