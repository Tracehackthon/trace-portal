## 接入注意

- 背景是共用环境，不是四态整页；面板、文字、连线和节点由代码实现。环境已经足够浅，避免再叠首页强色调滤镜。
- 推荐在 1672 × 941 基准场景中等比显示；非同比例视口的 cover 裁切由 UI 调整，不能保证所有边缘山体都完整保留。
- 两姿态必须用相同“源像素比例”，不要硬设为相同 CSS 宽度。例如 scale 0.065：站立宽 70.59、高 54.535；起飞宽 75.14、高 78.975。锚点位置乘相同比例后与路径点重合。
- 两幅静态姿态只支持站立/起飞切换和路径位移，不代表自然连续振翅。小于 1–2 源像素的羽毛边缘有原修复估算限制。
- 去 UI 后的遮挡区域由生成推补，不是原始隐藏像素的精确恢复；本任务只完成可接入素材，尚未写入 app/plugin。
