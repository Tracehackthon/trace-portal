## 构图判断与生产

已亲看五张参考及 home / matters / chain 的四张干净背景。既有资源的中部密集山体、上左枝影、下右前景枝叶或额外球体与这组高留白工作现场不同，因此从 01 单独去除 UI 补一张环境。五态山水仅轻微地形差异，继续使用同一背景，不生成五张整页或第二张无依据备选。

生成要求清除文字、品牌、卡片、控件、输入框、头像、鸟、节点和连线；保留上半与中央象牙白青绿留白、右上淡玉色圆月、两侧低山框景、底部珍珠色水面与少量暖金反光。结果亲看无可见 UI/字/节点/鸟，符合这个资源层的用途。不是逐像素还原，不保证被面板遮挡处与原图完全相同。

- 实际 prompt：`prompt-v1.txt`。
- 工具：内置 image_gen；接口未暴露模型 ID，因此记录未知，不声称“最新型号”。
- 1 次调用，0 次失败/重试。
- 工具原始输出保留在 generated_images；工作区不可变副本为 `originals/worksite-environment-generated-v1.png`；`ready` 是同哈希复制，没有裁切、缩放或脚本透明修复。
- 来源和输出绝对路径、输入/输出 SHA-256、尺寸、目视结论均见 `manifest.json`。

## 鸟的使用

直接复用首页 `images/repaired/` 两姿态，没有重新生图，没有把此前脚本授权扩展到任何新图。首页原始生成及修复凭据仍保留；本批清单链接到原修复 manifest，并核验 hash。

以源像素统一比例 `s = .09` 定位脚锚到节点，不能给两个裁剪尺寸不同的图片相同 CSS 宽度：

| 姿态 | CSS 宽/高 | 脚锚 | 以脚锚为原点的 left/top |
| --- | --- | --- | --- |
| perched | 97.74 × 75.51 | (772, 588) | −69.48 / −52.92 |
| takeoff | 104.04 × 109.35 | (750, 955) | −67.5 / −85.95 |

已查看旧的深绿/灰底小尺寸检查图；白腹与白颈保留，透明区域不是棋盘格。仅两个姿态，不是连续自然扇翅。高倍率边缘仍可能有 1–2 px 的估计误差；最终场景背景/动画需 UI owner 核验。

## 许可与验证边界

图片为项目生成素材及其已授权修复派生，不冒充外部开源组件，不给图片杜撰 MIT/OFL 许可。保留生成与修复 provenance。字体的 OFL 许可独立存于 `../fonts/`。

重放检查（仓库上层 workspace 为 cwd）：

```powershell
python artifacts/trace-worksite-v1-20260915/images/validate_assets.py
```

该检查读取图片校验 PNG、尺寸、alpha、复制/来源 hash 并更新本目录 manifest；不修改任何像素。静态素材有效/目视通过不等于 UI 可读性、浏览器/file:// 加载、真实宿主或交互验收通过；这些本 owner 未运行。
