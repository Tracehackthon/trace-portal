# Trace 工作现场独立 UI 模块

<!-- impeccable:product-schema 1 -->
## Platform
Web 原生 DOM；未来可被既有 Electron 窗口加载。本批不接入 app。
## Product purpose
在当前工作中核对过去理解的本次使用、工作影响与新发现，并将结果同原有理解比较。事实、解释、建议修改分离，长期理解只在明确确认后改变。
## Authority and scope
产品沿用既有 desktop PRODUCT.md；唯一视觉方向为用户指定 Trace工作现场_UI状态_v1 的五图与 README。本模块遵守 coordination/CONTRACT.md，不持有第二份业务状态。
## Truth boundary
UI 显式标注示例及未连接；不假发消息、不假开原型、不把演示记录称为验收事实。图外补齐工作选择、空状态、纠错和修改确认。
