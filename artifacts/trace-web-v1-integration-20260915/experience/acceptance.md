## A. 新输入 → 同一件事 → 原表达找对照 → 接受／拒绝 → 回原处

1. 首页输入 **“按钮越少，第一次填写就越容易吗？🧪 我想先比较必要步骤。”**，提交一次。记宿主 ID 为 M；原文完整，understanding 为空，无自动标题改写、旧停点或“已验证”结论。只留下后返回首页也成立。
2. 从 M 气泡重开。选中原话 **“按钮越少，第一次填写就越容易吗？”** 并找对照；记录来源 S、字段、原文精确 start/end、baseVersion、返回位置 R。对照首屏展示该片段与 M，且原页草稿/滚动未丢。
3. **拒绝门槛行为**：进入对照不能要求先保存“我的理解”、先跟 AI 聊一轮、先关联收藏示例、先建工作或先去设置授权；也不能偷偷把原句写进理解让接口通过。理解仍为空。
4. 手工粘贴材料 C1：**“验收材料 A：步骤少了，但两个必填条件被藏起来，首次填写者需要返回补全。”**；标“用户粘贴，来源未核验”，无伪 URL/作者。仅打开/比较/写评价不改理解与版本。
5. 选择“接为限制”，核对指向原选句后确认。宿主新增 M→C1 的确切关系，理解仍为空；原表达未改。返回原处恢复 R 与选句，旁边可见“已接为限制／理解未改”，不要仅有 toast。
6. 再粘贴 C2：**“验收材料 B：某按钮颜色变化。”**，点“这次无关”。C2 原材料仍可在未关联内容找回，M 无新关系/理解变更；返回还是 R。再取消一次查找，同样无隐式提交。

## B. 自己写理解 → 工作带入 → 结果回来 → 下次取新版本

1. 在 M 明确“自己写”，输入 **“先保留必要条件，再减少操作步骤。这里只讨论首次填写。”** 并显式保存为 U1/V1；原输入与 C1 关系仍在。保存留当前编辑位置；“先放这里”才收起。回首页再打开 M 应看到 U1，不生成第二件事。
2. 选中 U1 第一处，进入带入面；核对本次工作 W、Agent/项目/任务、选文、V1、角色 trial、范围 current-task。取消一次应不产生 intake/发送；再确认一次只创建本地带入 I1。未连接外部时必须显示“尚未发送”，provided/decision/artifact/usage 全不因本地保存自动成功。
3. 切换为 exclude，实际 context 不含 I1，但来源与历史快照仍在；再改为 reference 或 trial，context 中用途说明真实不同。另一工作 W2 的草稿/角色/结果不得混入。
4. 工作现场点“带回结果”。先看 U1/V1 的当时停点和 W，事实初始为空。输入事实 **“验收数据：移除说明后，第一次填写漏掉了一个必要条件。”**、解释 **“可能是条件提示被一并移除了。”**、未知 **“还未验证其他表单。”**。先点“只留下结果”：保存 R1→M/W/I1；U1/V1 不变，不能进入“理解已更新”。
5. 输入拟修订 **“先保留可见的必要条件，再减少操作步骤；步骤少不等于首次填写更容易。”**，查看 before/after 并取消一次，不变更。重新确认且宿主成功后才写 U2/V2、receipt，页面显示原处实际差异与 R1 依据；关系“限制”本身不等于确认。
6. 回 M 原位置、回首页、再用搜索/全部找 M、刷新后重开，当前理解都是 U2/V2。I1 仍保存当时 U1/V1，显示“之后已有修订”而不自动重做旧工作。点“再试一次”重新确认形成 I2，其 sourceVersion=V2；不自动新建外部任务。
7. 独立分支：确认修订后立即撤销，文本恢复 U1、版本继续单调递增，R1/C1 不丢；若之后已保存新编辑，旧撤销必须拒绝并保新内容。不得倒回整个 state JSON。
